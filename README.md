# Point2PDF

Convert any file to PDF with a sleek drag‑and‑drop interface. Uses LibreOffice in headless mode for reliable, high‑fidelity conversions.

## Features
- Drag & drop or browse for files
- Customise the output PDF name
- Silent, no pop‑up windows
- Modern web‑based UI (Eel + HTML/CSS/JS)

## Requirements
- Python 3.8+
- LibreOffice installed (www.libreoffice.org)
- Python packages: `eel` (install with `pip install eel`)

## How to run
1. Clone the repository
2. Install dependencies: `pip install eel`
3. Ensure LibreOffice is installed and adjust `SOFFICE_PATH` in `point2PDF.py` if needed
4. Run: `python point2PDF.py`
5. The app window will open – drag a file, set a name, and click Convert.
